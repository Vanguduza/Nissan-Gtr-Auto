# Vanguduza Project Truth Protocol

Never infer project truth from chat memory, the GitHub default branch, the newest timestamp, or the current checkout. Read `PROJECT_CANONICAL_STATE.json` before planning, coding, merging, building, packaging, deploying, or releasing. Inspect divergent branches and source-of-truth/decision documents before declaring an implementation canonical. Silent feature thinning is forbidden. Every pushed commit is automatically logged under `docs/project-state/` with commit, parent, branch, author, timestamp, changed files, tree SHA and diff digest. Releases remain blocked while `canonical_state.release_blocked` is true. Nissan GTR additionally has application-specific Customer/POS lineage guards; those stronger guards take precedence over this repository-level bootstrap.
